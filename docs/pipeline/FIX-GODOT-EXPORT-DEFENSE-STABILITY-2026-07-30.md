## Fix: Add `defense` and `stability` to Godot JSON export payload (2026-07-30)

The `btn-export` click handlers in `apps/web/src/main2d.ts` and `apps/web/src/main3d.ts` were building a `stats` JSON object that omitted `defense` and `stability`, even though both fields were already present on the `StatSheet` returned by `StatDeriver.derive()` and were correctly displayed in the HUD stat tables. Two lines — `defense: sheet.defense` and `stability: sheet.stability` — were appended to the `stats` block in each export handler, matching the lowercase field names required by the `StatSheet` interface and the Godot `KijoStats.from_json()` loader. No other fields, types, or files were changed. TypeScript verification via `tsc -p tscheck2d.json --noEmit` and `tsc -p tscheck3d.json --noEmit` both exited 0.
